## 1. 명명 규칙 (Naming Conventions)

[`기존안/06 §0`](기존안/06_데이터_모델_설계서.md) 의 규칙을 그대로 계승한다.

### 1.1 테이블

| 규칙      | 형식        | 예                        |
| --------- | ----------- | ------------------------- |
| 접두어    | `DXAPI_`    | `DXAPI_USR_USER_M`        |
| 마스터    | `_M` 접미사 | `DXAPI_API_DEF_M`         |
| 이력/로그 | `_L` 접미사 | `DXAPI_CALL_HIST_L`       |
| 매핑      | `_MAP_M`    | `DXAPI_EXT_SYS_API_MAP_M` |

### 1.2 컬럼

- **단어사전(`wordic/word.txt`) 우선**. 매핑되는 표준용어가 있으면 그대로 사용.
- 매핑이 없으면 단어사전의 단어를 **조합** 하여 생성.
- 기술 용어 (`HTTP`, `JSON`, `JDBC`, `URL`, `IP`, `SQL`, `MS`, `POOL`, `TIMEOUT`, `DB`, `JWT`) 는 사전에 없어도 그대로 유지.

### 1.3 인덱스 / 시퀀스 / 제약

| 종류          | 형식                         | 예                    |
| ------------- | ---------------------------- | --------------------- |
| 일반 인덱스   | `IX_<테이블축약>_<핵심컬럼>` | `IX_CALL_HIST_TRC`    |
| 유니크 인덱스 | `UX_<테이블축약>_<핵심컬럼>` | `UX_API_DEF_REQ_PATH` |
| 시퀀스        | `SEQ_<용도>`                 | `SEQ_API_NO`          |
| Primary Key   | `PK_<테이블축약>`            | `PK_USR_USER`         |
| Foreign Key   | `FK_<자테이블>_<부모테이블>` | `FK_API_DEF_DATA_SRC` |
| Check         | `CK_<테이블축약>_<컬럼>`     | `CK_USER_STTUS`       |

### 1.4 감사 컬럼 (모든 테이블 공통)

| 컬럼    | 타입         | 의미       |
| ------- | ------------ | ---------- |
| `REGID` | VARCHAR2(20) | 등록자ID   |
| `REGDT` | TIMESTAMP    | 등록일시   |
| `REGIP` | VARCHAR2(50) | 등록IP주소 |
| `MODID` | VARCHAR2(20) | 수정자ID   |
| `MODDT` | TIMESTAMP    | 수정일시   |
| `MODIP` | VARCHAR2(50) | 수정IP주소 |

> 기존안의 10개 감사 컬럼 중 `REGMENU/REGPGM/MODMENU/MODPGM` 4종은 모니터링 부담 대비 효용이 낮아 제외(필요 시 추후 추가).

## 3. DDL — 사전 준비

### 3.1 Tablespace · 사용자

```sql
-- 비즈니스 메타 (사용자/API/연계시스템/데이터소스/승인/캐시/코드)
CREATE TABLESPACE TS_DXAPI_META
  DATAFILE 'ts_dxapi_meta_01.dbf' SIZE 1G AUTOEXTEND ON NEXT 256M MAXSIZE 32G
  EXTENT MANAGEMENT LOCAL AUTOALLOCATE
  SEGMENT SPACE MANAGEMENT AUTO;

-- 호출 이력 (대량 INSERT + 파티션 drop 전용. 비즈니스 DB 와 분리)
CREATE TABLESPACE TS_DXAPI_MON
  DATAFILE 'ts_dxapi_mon_01.dbf' SIZE 2G AUTOEXTEND ON NEXT 512M MAXSIZE 64G
  EXTENT MANAGEMENT LOCAL AUTOALLOCATE
  SEGMENT SPACE MANAGEMENT AUTO;

-- 애플리케이션 스키마
CREATE USER DXAPI IDENTIFIED BY "<vault-managed>"
  DEFAULT TABLESPACE TS_DXAPI_META
  QUOTA UNLIMITED ON TS_DXAPI_META
  QUOTA UNLIMITED ON TS_DXAPI_MON;

GRANT CREATE SESSION, CREATE TABLE, CREATE SEQUENCE, CREATE VIEW,
      CREATE MATERIALIZED VIEW, CREATE PROCEDURE TO DXAPI;
```

### 3.2 시퀀스

```sql
-- API 번호 / 연계시스템 ID / 데이터소스 ID 는 `prefix + YYYYMMDD + 3자리` 패턴이라
-- 매일 리셋되는 일련번호로 충분하다. 기존안과 동일 정책.
CREATE SEQUENCE SEQ_DAILY_API_NO       START WITH 1 INCREMENT BY 1 NOCACHE NOORDER;
CREATE SEQUENCE SEQ_DAILY_CONTCT_SYST  START WITH 1 INCREMENT BY 1 NOCACHE NOORDER;
CREATE SEQUENCE SEQ_DAILY_DATA_SRC     START WITH 1 INCREMENT BY 1 NOCACHE NOORDER;

-- 단순 증가 시퀀스
CREATE SEQUENCE SEQ_CALL_HIST  START WITH 1 INCREMENT BY 1 CACHE 100 NOORDER;
CREATE SEQUENCE SEQ_USER_APPR  START WITH 1 INCREMENT BY 1 CACHE 20  NOORDER;
CREATE SEQUENCE SEQ_REFRESH    START WITH 1 INCREMENT BY 1 CACHE 50  NOORDER;
CREATE SEQUENCE SEQ_DS_STAT    START WITH 1 INCREMENT BY 1 CACHE 100 NOORDER;
```

> 일별 시퀀스는 매일 자정에 1로 리셋하는 DBMS_SCHEDULER 잡을 등록. 또는 SEQUENCE 를 사용하지 않고 `MAX(seq) + 1 WHERE id LIKE 'A20260517%'` 패턴을 코드에서 처리하는 것도 가능. **권장은 후자** — 트랜잭션 안정성이 더 높다.

### 10.1 자동 파티션 drop 스케줄 잡

```sql
BEGIN
  DBMS_SCHEDULER.CREATE_JOB(
    job_name        => 'JOB_DROP_OLD_CALL_HIST',
    job_type        => 'PLSQL_BLOCK',
    job_action      => q'[
      DECLARE
        v_high_date  DATE;
        v_cutoff     DATE := TRUNC(SYSDATE) - 7;
      BEGIN
        FOR p IN (
          SELECT partition_name, high_value
          FROM   user_tab_partitions
          WHERE  table_name = 'DXAPI_CALL_HIST_L'
            AND  partition_name <> 'P_INIT'
        ) LOOP
          EXECUTE IMMEDIATE
            'SELECT '||p.high_value||' FROM dual' INTO v_high_date;
          IF v_high_date <= v_cutoff THEN
            EXECUTE IMMEDIATE
              'ALTER TABLE DXAPI_CALL_HIST_L DROP PARTITION '||p.partition_name||' UPDATE GLOBAL INDEXES';
          END IF;
        END LOOP;
      END;
    ]',
    start_date      => SYSTIMESTAMP,
    repeat_interval => 'FREQ=DAILY;BYHOUR=3;BYMINUTE=0',
    enabled         => TRUE,
    comments        => '호출 이력 7일 초과 파티션 자동 drop'
  );
END;
/
```
