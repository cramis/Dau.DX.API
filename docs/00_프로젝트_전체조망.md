## 1. 궁극 목표

**"내부 DB 데이터를, 관리자가 SQL 등록만으로 표준 REST API 로 만들고, 외부 시스템에 인증키·IP·기간·매핑으로 통제해 *안전하게* 노출하는 멀티-DB 셀프서비스 API 게이트웨이."** (기존 EzAPI 후속. 출처 [`기존안/01 §1.2`](reference/기존안/01_프로젝트_개요_및_목표.md))

가치 2축.

- **축A — 셀프서비스 API 제작.** 코딩 없이 데이터소스·SQL·파라미터·응답 컬럼 등록만으로 API 생성.
- **축B — 통제된 안전 노출.** 인증키(HMAC)·IP·이용기간·매핑 4단 검증 + 응답/요청 마스킹 + 호출 이력.

"끝났다"의 정의(PRD §0). 외부 시스템이 `X-Cert-Key` 로 `/api/sample/{path}` 호출 → 4단 통과 → 대상 DB SQL 실행 → 마스킹 응답 → `DXAPI_CALL_HIST_L` 적재, 관리자가 모니터링에서 그 호출 확인. **이 P0 端-端은 실 dev Oracle 에서 검증 완료.**

## 4. 구현 상세 (어떻게) — ✅/🟡 역량 앵커

> 경로는 `backend/src/main/java/ac/donga/dxapi/` 기준 패키지-상대. 상세 = [`04_backend_가이드.md`](guide/04_backend_가이드.md).

**인증·세션.** `auth/AuthController`(login/logout/refresh) → `auth/AuthService`(bcrypt 검증 + `JwtProvider` HS256 발급, Access 15분·Refresh 24시간 jti) → `auth/RefreshTokenMapper`(`DXAPI_TKN_RFSH_TOKEN_M` revoke·회전). `auth/JwtAuthFilter`(Bearer→`AuthPrincipal`), `auth/AuthSupport`(requireLogin/requireAdmin). BFF httpOnly 쿠키는 `frontend/lib/bff.ts` `backendProxy`.

**셀프서비스 API 등록.** `apidef/ApiDefService` — 채번 `A+YYYYMMDD+seq3`, `check-path` 유니크, DS 존재 검증, `SqlPolicy.check`(method 기반), params/resps full-replace. `apidef/SqlValidationService`(prepare 시연). 매퍼 `ApiAdminMapper.xml`(부모+params+resps).

**데이터소스.** `datasource/DataSourceService` — 채번 `DS+date+seq`, 중복명, 참조 API 사용중 차단, 변경/삭제 시 `gateway/DataSourceRegistry.evict`(풀 hot-swap). 비번 `SecretCipher.encrypt` 저장. `test-connection` 임시 풀 검증.

**연계시스템.** `extsystem/ExtSystemService` — 채번 `E+date+seq`, `CertKeyService.generate`(평문 1회 노출)+HMAC 저장, allowedIps JSON(CLOB), mappedApis full-replace, `regenerate-key`, `RATE_LMT_PER_MIN` override(#4b).

**게이트웨이 파이프라인.** `gateway/GatewayController` `GET/POST /api/sample/{apiPath}` → `GatewayService.handle`: ① `verify` 4단(`CertKeyService.hash` 조회→ACTIVE→`IpWhitelistChecker` CIDR→기간→`countMappedApi`) ② `RateLimiter.tryAcquire`(연계별/전역) ③ 필수 파라미터 ④ `SqlExecutor.execute`(바인딩+`MaskingApplier` 응답 마스킹) ⑤ `CallHistoryQueue.enqueue`(요청 PII 마스킹본). 외부 노출이라 INTERNAL_ERROR 상세 숨김·traceId 추적.

**호출 이력·모니터링.** 쓰기 = `monitoring/CallHistoryBatchWriter`(@Scheduled 1초/100건 `batchUpdate`). 읽기 = `MonitoringService`(history 동적필터 ✅) + `StatsCalculator`(KPI·분당 시리즈 — 백엔드 ✅, FE 연결 대기 🟡).

**승인.** `approval/ApprovalService` — 가입 승인→사용자 ACTIVE, API 사용 승인→`DXAPI_CONTCT_SYST_API_MAP_M` 매핑 추가. PENDING 가드.

**보안 강화(본질 안전축).** `SqlPolicy`(#2/C4)·`SecretCipher`(#3)·`RateLimiter`(#4a·#4b)·`MaskingApplier.maskParamsForLog`(#1). 설계·로그 = [`06_보안강화_설계.md`](guide/06_보안강화_설계.md).

**프론트 연동 현황.** 실 백엔드 프록시 = API/DS/연계/승인 CRUD·monitoring history·auth. mock 잔존 = 본인정보·회원가입·비번찾기·monitoring stats·import. 상세 = [`05_frontend_BFF_이관_로그.md`](guide/05_frontend_BFF_이관_로그.md).
