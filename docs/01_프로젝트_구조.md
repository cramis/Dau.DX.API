## 1. 루트 구조

```
Dau.DX.API/
├── backend/            Spring Boot(Java 21·Gradle·MyBatis) — 실 API 서버
├── frontend/           Next.js(App Router) — 관리자 콘솔 + BFF
├── mcp/                TypeScript MCP 서버 — AI 초안등록 도구
├── mockup/             mockup 단계 프론트 원본 (역사 보존, 따르지 말 것)
├── docs/               문서 허브 — 진입점 = docs/README.md
├── .mcp.json           repo 동봉 MCP 설정 (Claude Code 가 dxapi MCP 자동 연결)
├── docker-compose.yml  로컬 구동 구성
├── .gitea/workflows/   Gitea CI 워크플로우
├── .github/            GitHub 보조 (modernize)
├── .agents/ .codex/    AI 에이전트 보조 설정 (skills·config)

3개 앱(backend·frontend·mcp)은 각각 독립 빌드·배포 단위 — **Dockerfile 과 `deploy/kustomize/`(K8s) 를 각자 보유**.

```
backend/
├── build.gradle.kts / settings.gradle.kts / gradlew

### 패키지 지도 (`ac.donga.dxapi.*`)

| 패키지        | 역할                            | 핵심 클래스                                                                                                                                                                  |
| ------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `auth/`       | JWT 로그인·세션                 | `AuthService`(bcrypt·5회 잠금) · `JwtProvider` · `JwtAuthFilter` · `AuthSupport`(requireLogin/requireAdmin) · `RefreshTokenMapper`(회전·revoke)                              |
| `user/`       | 사용자 admin CRUD               | `UserService` · `UserController`                                                                                                                                             |
| `apidef/`     | 셀프서비스 API 등록             | `ApiDefService`(채번·path 유니크) · `SqlValidationService` · `TestRunService`(ad-hoc 실행·롤백) · `OpenApiSpecBuilder`+`DocsController`(공개 OpenAPI)                        |
| `datasource/` | 데이터소스 관리                 | `DataSourceService`(CRUD·test-connection) · `SwapImpact`/`SwapRunRequest`(hot-swap) · `SchemaService`(MCP 용 스키마 조회)                                                    |
| `extsystem/`  | 연계시스템·인증키               | `ExtSystemService`(HMAC 키 발급/재발급·IP·매핑)                                                                                                                              |
| `gateway/`    | **핵심 — 외부 호출 파이프라인** | `GatewayService`(4단 검증) · `CertKeyService` · `IpWhitelistChecker` · `SqlExecutor` · `MaskingApplier` · `RateLimiter` · `SqlPolicy` · `DataSourceRegistry`(동적 커넥션 풀) |
| `monitoring/` | 호출 이력·통계                  | `CallHistoryQueue`+`CallHistoryBatchWriter`(1초/100건 배치) · `MonitoringService` · `StatsCalculator`                                                                        |
| `approval/`   | 승인 워크플로우                 | `ApprovalService`(가입→ACTIVE, API→매핑)                                                                                                                                     |
| `ops/`        | 운영 메타                       | `OpsController`(health/version)                                                                                                                                              |
| `common/`     | 횡단 관심사                     | `ApiResponse` · `ErrorCode` · `GlobalExceptionHandler` · `SecretCipher`(AES-256-GCM) · `TraceIdFilter`                                                                       |
| `config/`     | 설정 빈                         | `CryptoConfig`(bcrypt12) · `SchedulingConfig` · `LocalDataSeeder`                                                                                                            |

규약·확장 레시피(새 도메인 추가법 등) = [`guide/04_backend_가이드.md`](guide/04_backend_가이드.md).

## 3. frontend — Next.js App Router

```
frontend/
├── next.config.ts / playwright.config.ts / Dockerfile / deploy/kustomize/
├── app/
│   ├── (admin)/        관리자 콘솔 — dashboard·api-list(+new·[id])·datasource(+swap 마법사 5단계)
│   │                   ·ext-system·users·approvals(user·api)·monitoring(logs·incidents·rules)·me
│   ├── (auth)/         login · signup · forgot-password
│   ├── api/mock/       ★ BFF 레이어 — 이름은 mock 이지만 다수가 backendProxy 로 실 백엔드 프록시
│   ├── api/auth/       login/logout — httpOnly 쿠키 처리
│   ├── api/sample/     게이트웨이 샘플 호출 데모
│   ├── api/try/[path]  /docs Try-it 공개 프록시 (실제 게이트웨이 호출·이력 적재)
│   └── docs/           공개 API 문서 화면 (OpenAPI 실연동)
├── components/         ui/(공용)·design/(디자인 시스템)
├── lib/                bff.ts(backendProxy ★연동 핵심)·backend.ts·schemas/(zod 4종)·mock*(잔존 mock 데이터)
├── types/ public/
└── e2e/                Playwright — day1~6 spec + tryit·docs-tryit·real-backend (README 참고)
```

**⚠ `app/api/mock/` 함정.** 디렉터리명만 보고 mock 으로 판단하지 말 것. 실 프록시 전환분(API·DS·연계·승인·모니터링·import 등)과 잔존 mock(본인정보 수정·signup·forgot-password)이 섞여 있다 — 현황 = [`guide/05_frontend_BFF_이관_로그.md`](guide/05_frontend_BFF_이관_로그.md).

## 6. 신규 코드 배치 규칙

- **백엔드 새 도메인** → `ac.donga.dxapi.<도메인>/` 패키지 신설 + `resources/mapper/<도메인>Mapper.xml` + `test/.../<도메인>/` 미러. 레시피 = [`guide/04_backend_가이드.md`](guide/04_backend_가이드.md).
- **프론트 새 화면** → `app/(admin)/` 또는 `app/(auth)/` 라우트 그룹. 백엔드 연동은 `app/api/mock/` 에 라우트 추가 후 `lib/bff.ts` `backendProxy` 사용(직접 fetch 금지 — httpOnly 쿠키 경유).
- **MCP 새 도구** → `mcp/src/tools.ts` 에 추가, `smoke.mjs` 검증.
- **문서** → [`README.md`](README.md) §유지 규칙 따름.
