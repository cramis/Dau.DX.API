# 02. 화면 명세 (Mockup 기준)

> 12개 화면의 라우트·목적·핵심 필드·동작만 간략히. 디자인 토큰·반응형·상세 검증 규칙은 Mockup 진행하며 추가한다.

## 2. 화면별 핵심

### 2.1 로그인 (`/login`)
- 필드: 아이디, 비밀번호
- 동작: `[로그인]` → mock JWT → `/api-list` 이동. `[비밀번호 찾기]` `[회원가입]` 링크.

### 2.2 회원가입 (`/signup`)
- 필드: 아이디(중복확인), 비밀번호+확인, 이름, 휴대폰, 이메일, 기관명, 부서명, 전화번호, 개인정보 동의
- 동작: 제출 → 승인 대기 상태로 등록(Mock).

### 2.3 비밀번호 찾기 (`/forgot-password`)
- 필드: 이메일
- 동작: `[재설정 메일 발송]` → 토스트 알림(실제 메일 발송 없음). 이메일 존재 여부 노출 금지.

### 2.4 API 목록 (`/api-list`)
- 컬럼: API번호, API명, 그룹, 메서드, 상태, 요청경로, 데이터소스, 등록일시, 수정일시, 인증여부
- 동작: 행 클릭 → 수정 화면(`/api-list/[id]`). `[등록]` → `/api-list/new`. 검색/정렬/페이징.

### 2.5 API 등록·수정 (`/api-list/new`, `/api-list/[id]`)
- 탭 구성:
  1. **기본정보** — API명, 그룹, HTTP 메서드, 요청경로(중복확인), 상태, 데이터소스, 인증여부, 문서노출
  2. **SQL 소스** — Monaco Editor (PL/SQL 하이라이트)
  3. **입력 파라미터** — 동적 행 (이름·타입·필수·기본값)
  4. **응답 컬럼** — 컬럼명·타입·표시명·마스킹 룰
- 동작: `[중복확인]` `[SQL 검증]`(Mock 응답) `[실행 테스트]`(Mock 결과) `[저장]`.

### 2.6 데이터소스 (`/datasource`)
- 등록 폼: 데이터소스명, DB 종류(Oracle/PG/MySQL), JDBC URL, 사용자, 비밀번호, 풀 사이즈(min/max), 쿼리 타임아웃
- 동작: `[연결 테스트]` (Mock 성공/실패), 저장 시 hot-swap 흉내.

### 2.7 연계시스템 (`/ext-system`)
- 등록 폼: 시스템명, 인증키(자동 발급, 1회 표시), 허용 IP(textarea, CIDR), 사용 시작/종료, 매핑 API(multi-select), 담당자, 비고
- 동작: `[재발급]` 시 즉시 무효화 흉내. 매핑 변경 시 토스트.

### 2.8 실시간 모니터링 (`/monitoring`)
- 필터: 기간(기본 24h), 연계시스템, API, HTTP 메서드, 응답코드, IP
- 컬럼: 호출시각, 인증키(prefix 만), 클라이언트 IP, 요청경로, HTTP 메서드, 파라미터(요약), 응답코드, 응답시간(ms), trace-id
- 차트: 응답코드별 시간대 막대그래프
- 동작: 5초 자동 새로고침(toggle), 행 클릭 → 상세 모달.

### 2.9 API 문서 (`/docs`)
- 좌: API 그룹 트리. 우: 상세(설명·인증·입력/응답·curl 예시·OpenAPI 다운로드).
- 비로그인 접근 가능. `Document 표시 여부 = TRUE` 인 API 만.

### 2.10 API 승인 (`/approvals/api`)
- 컬럼: 신청일시, 신청자, 신청 API, 사유, 상태, `[승인]` `[반려]`
- 동작: 승인 → 자동 매핑(Mock). 반려 → 사유 입력 모달 → 토스트.

### 2.11 사용자 승인 (`/approvals/user`)
- 컬럼: 신청일시, 아이디, 이름, 이메일, 기관, 부서, 상태, `[승인]` `[반려]`

### 2.12 사용자 관리 (`/users`) — admin
- 컬럼: 아이디, 이름, 이메일, 기관, 부서, 권한, 활성여부, 마지막 로그인, 액션
- 상세: `/me` 와 동일 폼 + 권한·활성여부 변경 가능

### 2.13 본인 정보 (`/me`) — 화면 12에 해당
- 탭: 기본 정보 / 비밀번호 변경 / 세션(로그아웃, 모든 기기 로그아웃)

## 3. 공통 컴포넌트

- `<DataTable>` — 가상 스크롤·정렬·검색·페이징
- `<FormSection>` — 폼 섹션 헤더 + 필드 그룹
- `<ConfirmDialog>` — 삭제·비활성화 확인
- `<Toast>` — 성공/실패 알림
- `<EmptyState>` — 데이터 없음 + 안내 + CTA
