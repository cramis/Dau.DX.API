## 2. 다른 PC 최초 셋업

```bash
git clone https://github.com/cramis/Dau.DX.API.git
cd Dau.DX.API
git checkout dev-01            # 작업 브랜치 (main 아님)
cd frontend && bun install     # backend 는 gradlew 가 의존성 자동 다운로드
```

필요 도구(git 밖, OS 설치).
- **JDK 21** — `winget install EclipseAdoptium.Temurin.21.JDK`. `java` 가 PATH 에 없어 빌드 전 매번 `JAVA_HOME` 지정.
- **bun** — `powershell -c "irm bun.sh/install.ps1 | iex"`. (Node·Docker·sqlplus 불필요.)

## 3. 구동 (端-端 데모)

```powershell
# 백엔드 (:8080) — 절대경로, 시드 ON
$env:JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-21.0.11.10-hotspot"  # 설치판 경로에 맞게
$env:DXAPI_SEED_ENABLED="true"
cd <repo>\backend; .\gradlew.bat bootRun

# 프론트 (:3000) — 새 터미널
cd <repo>\frontend; bun run dev
```

- 로그인 데모 계정 `admin01 / admin01!` (ADMIN). 시드 = `config/LocalDataSeeder.java`(admin01·user01·user02).
- 부팅 확인 = `/actuator/health` 의 db 지표(UP=Oracle 연결). 상단 칩이 `local · 0.0.1-SNAPSHOT` 표시.

### 테스트
- 통합/수용 IT(실 dev Oracle) — `gradlew test -Dit.devdb=true`.
- e2e — 서버 2개 띄운 뒤 `cd frontend; bunx playwright test e2e/day1-smoke.spec.ts e2e/real-backend.spec.ts`.

## 4. ⚠ 건드리면 안 되는 것

- **`DXAPI_SECRET_KEY` 변경·설정 금지.** DS 비밀번호가 **기본 마스터키로 AES-GCM 암호화 저장**(#3)됨. 다른 키로 부팅 시 기존 암호문 복호 불가 → 게이트웨이 DB 연결 실패. **기본값 그대로 부팅.**
- **dev Oracle 네트워크 도달성** = 이어작업 최대 변수. `application-local.yml` 기본값이 `cramis-macbookpro.tail181647.ts.net:1521/freepdb1`(유저 `dxapi`, Oracle 26ai Free)를 가리킨다 — **Tailscale 연결 + 해당 MacBook 의 Oracle 컨테이너 기동 필요**. 안 닿으면 앱은 떠도 health db DOWN. (구 사내 `168.115.36.230/DEVORA19` 는 2026-06-07 폐기.)
  - 다른 DB 쓰려면 env override — `DXAPI_DB_URL`·`DXAPI_DB_USER`·`DXAPI_DB_PASSWORD`.
- 데모 연계시스템 `E20260509001` 은 dev 검증 잔재로 `RATE_LMT_PER_MIN=0`(무제한) 상태. 운영 무관.
