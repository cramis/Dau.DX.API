> Dau.DX.API 백엔드 MetaDB 14테이블 레퍼런스. 테이블별 역할 + 컬럼 사전(컬럼·타입·NULL·설명) + PK/FK/제약/인덱스. 빠른 조회용. 정식 ERD·DDL 설계 근거 = `06_DB_모델링.md`, 실행 스크립트 = `07_DBA_DDL.sql`.

# 08. DB 테이블 레퍼런스 (Oracle 19c MetaDB)

이 문서는 백엔드가 사용하는 **메타 DB(스키마 `DXAPI`) 14개 테이블**을 테이블별로 빠르게 찾아보기 위한 레퍼런스다. 각 테이블의 **역할 한 줄 + 컬럼 사전 + 키/제약/인덱스**를 담았다. 원본 = [`07_DBA_DDL.sql`](07_DBA_DDL.sql)(SoT). 설계 근거·명명규칙 = [`06_DB_모델링.md`](06_DB_모델링.md).

> ⚠ 이 14테이블은 **앱 자체 메타 DB**(운영 데이터). 게이트웨이가 SQL 을 실행하는 **외부 등록 데이터소스**(`DXAPI_DATASOURCE_M` 에 행으로 등록됨)와 혼동 금지.

## 0. 한눈에 보기

| #   | 테이블                     | 접미사  | 역할                                      | Tablespace |
| --- | -------------------------- | ------- | ----------------------------------------- | ---------- |
| 1   | `DXAPI_USR_USER_M`         | \_M     | 사용자 마스터 (관리자/일반 계정)          | META       |
| 2   | `DXAPI_USR_EXT_SYS_M`      | \_M     | 연계시스템 마스터 (외부 호출 주체)        | META       |
| 3   | `DXAPI_DATASOURCE_M`       | \_M     | 데이터소스 마스터 (등록 외부 DB 연결정보) | META       |
| 4   | `DXAPI_API_DEF_M`          | \_M     | API 정의 마스터 (SQL→REST 한 건)          | META       |
| 5   | `DXAPI_API_PARAM_M`        | \_M     | API 입력 파라미터 (4 자식)                | META       |
| 6   | `DXAPI_API_RESP_M`         | \_M     | API 응답 컬럼 (4 자식)                    | META       |
| 7   | `DXAPI_EXT_SYS_API_MAP_M`  | \_MAP_M | 연계시스템↔API 매핑                       | META       |
| 8   | `DXAPI_USR_EXT_SYS_USER_M` | \_M     | 사용자↔연계시스템 매핑 (/docs 권한)       | META       |
| 9   | `DXAPI_CALL_HIST_L`        | \_L     | 게이트웨이 호출 이력 (일별 파티션)        | MON        |
| 10  | `DXAPI_USER_APPR_L`        | \_L     | 승인 이력 (가입+API사용 통합)             | META       |
| 11  | `DXAPI_EZ_CODE_M`          | \_M     | 공통 코드                                 | META       |
| 12  | `DXAPI_REFRESH_TOKEN_L`    | \_L     | JWT Refresh 토큰 (revoke 가능 jti)        | META       |
| 13  | `DXAPI_API_DOC_CACHE_M`    | \_M     | OpenAPI 스펙 영속 캐시                    | META       |
| 14  | `DXAPI_DS_RUNTIME_STAT_L`  | \_L     | 데이터소스 풀 사용률 시계열               | MON        |

**관계 요약.** `DATASOURCE_M`(3) ←FK– `API_DEF_M`(4) –FK→ `API_PARAM_M`(5)·`API_RESP_M`(6). `USR_EXT_SYS_M`(2) ↔ `API_DEF_M`(4) 은 `EXT_SYS_API_MAP_M`(7) 로 N:M. `USR_USER_M`(1) ↔ `USR_EXT_SYS_M`(2) 은 `USR_EXT_SYS_USER_M`(8) 로 N:M. `CALL_HIST_L`(9)·`DS_RUNTIME_STAT_L`(14) 는 운영 이력.

**감사 컬럼 공통.** 대부분 테이블은 감사 컬럼을 가진다 — `REGID`(등록자), `REGDT`(등록일시, `DEFAULT SYSTIMESTAMP`), `REGIP`(등록IP), `MODID`(수정자), `MODDT`(수정일시), `MODIP`(수정IP). 각 표 아래 **감사** 항목에 그 테이블이 실제로 가진 감사 컬럼 조합을 표기한다.

**ID 채번 규칙.** 사용자=수동 입력 / 연계시스템=`E+YYYYMMDD+seq3` / 데이터소스=`DS+YYYYMMDD+seq3` / API=`A+YYYYMMDD+seq3`.
