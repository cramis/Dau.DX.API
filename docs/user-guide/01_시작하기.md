> 콘솔에 처음 들어오는 관리자를 위한 안내. 로그인 방법, 권한 구분, 로그인 후 첫 화면, 그리고 회원가입·비밀번호 찾기의 현재 상태를 설명한다.

# 01. 시작하기

[← 목차로](README.md) · 다음: [02. 빠른 시작 — 전체 흐름](02_빠른시작_전체흐름.md)

## 이 화면은 무엇

콘솔에 들어오려면 먼저 로그인해야 한다. 로그인하지 않은 채 관리 화면(`/dashboard`, `/api-list` 등) 주소로 가면 자동으로 로그인 화면으로 보내진다.

## 로그인하기

1. 브라우저에서 콘솔 주소를 연다(개발 환경 기준 `http://localhost:3000`).
2. **아이디**(영소문자+숫자 5~16자)와 **비밀번호**를 입력한다.
3. **로그인** 버튼을 누른다. 처리 중에는 버튼이 "로그인 중..." 으로 바뀐다.
4. 성공하면 **API 관리** 화면(`/api-list`)으로 이동한다.

체험만 해보려면 로그인 화면 하단 **"Mockup 데모 계정"** 영역의 계정 카드를 클릭한다. 아이디·비밀번호가 자동으로 채워진다(계정 목록은 [목차 문서의 데모 계정](README.md#데모체험-계정) 참고).

### 로그인이 안 될 때

화면에 뜨는 안내 문구별 원인이다.

| 메시지 | 원인 | 해결 |
|---|---|---|
| 아이디 또는 비밀번호가 올바르지 않습니다. | 입력값 불일치 | 아이디·비밀번호 재확인 |
| 활성화되지 않은 계정입니다. 관리자 승인을 기다려주세요. | 계정이 PENDING(승인 전) 또는 INACTIVE(비활성) | 관리자 승인·활성화 필요 → [07. 승인 관리](07_승인관리.md) |
| 입력값을 다시 확인해주세요. | 형식 오류(글자 수 등) | 형식에 맞게 입력 |

> 보안 안내. 비밀번호를 연속 5회 틀리면 계정이 자동으로 비활성(INACTIVE)된다(무차별 대입 차단). 다시 쓰려면 관리자가 [사용자 관리](09_사용자_본인설정.md)에서 활성화해야 한다.

## 권한 — ADMIN 과 USER

| 권한 | 할 수 있는 일 |
|---|---|
| **ADMIN**(관리자) | API·데이터소스·연계시스템 등록/수정, 승인 처리, 사용자 관리 등 전체 |
| **USER**(일반) | 본인 정보 확인, 공개 API 문서 열람 등 제한된 범위 |

상단 우측에 본인 이름과 권한이 `홍길동 (ADMIN)` 처럼 표시된다. 그 옆 칩은 현재 환경(`local`/`dev`/`prod`)과 버전을 보여준다.

## 로그아웃

좌측 메뉴 맨 아래 **설정**(`/me`)에서 **로그아웃** 버튼을 누르면 세션이 종료되고 로그인 화면으로 돌아간다.

## 회원가입 🚧

> 🚧 **준비 중(mockup)** — 화면과 입력은 동작하지만, 신청 내용이 실제 DB에 저장되지는 않는다(데모 응답). 실제 가입 신청 저장은 후속 단계.

회원가입 화면(`/signup`)의 구성과 절차다.

1. **아이디** 입력 후 **중복확인** 버튼을 누른다. 사용 가능하면 "✓ 사용 가능한 아이디입니다.", 이미 있으면 "이미 사용 중인 아이디입니다." 가 뜬다.
2. 비밀번호·비밀번호 확인, 이름, 휴대폰번호(`010-XXXX-XXXX`), 기관명, 부서명, 이메일을 채운다. 전화번호는 선택이다.
3. **개인정보 수집·이용 동의(필수)** 체크박스를 켠다.
4. **회원가입** 버튼을 누른다. 완료되면 "회원가입 신청이 완료되었습니다. 관리자 승인을 기다려주세요." 안내 후 로그인 화면으로 이동한다.

가입 신청은 **PENDING** 상태로 만들어지고, 관리자가 [승인](07_승인관리.md)해야 로그인할 수 있다(승인 처리 흐름 자체는 실동작).

## 비밀번호 찾기 🚧

> 🚧 **준비 중(mockup)** — 메일 발송 기능이 아직 없다. 화면은 항상 성공처럼 응답한다.

비밀번호 찾기 화면(`/forgot-password`)에서 가입 시 등록한 **이메일**을 입력하고 **재설정 메일 발송**을 누른다. 보안상 이메일 존재 여부와 무관하게 동일한 안내("입력하신 이메일이 등록되어 있다면 재설정 메일을 발송합니다.")가 표시된다.
