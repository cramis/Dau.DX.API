## 이 화면은 무엇

운영 현황을 한눈에 보는 시작 화면이다(`/dashboard`). 지표는 **5초마다 자동 새로고침**된다.

상단의 빠른 이동 버튼으로 **+ 신규 API 등록**, **데이터소스**, **연계시스템** 화면으로 바로 갈 수 있다.

## 화면 구성

### 1) 핵심 지표 타일 (상단 4개)

| 타일 | 의미 |
|---|---|
| **등록 API** | 전체 API 수 + `ACTIVE · DRAFT` 내역 |
| **분당 호출량 (최근 30분)** | 분당 호출 수(RPM) + 최근 30분 누적 호출 건수 |
| **5xx 오류율 (최근 30분)** | 서버 오류 비율(%) + 5xx 건수 · p95 응답시간 |
| **진행 중 인시던트 / 올해 재시작** | 5xx가 급증하면 인시던트 1건으로, 평소엔 "올해 재시작 0건"으로 표시 |

### 2) 호출 추이 차트 · 인시던트 카드

- **최근 30분 호출 추이** — 2xx(정상)·4xx(요청오류)·5xx(서버오류)를 색으로 구분한 선 그래프. 호출이 없으면 안내 문구와 함께 샘플 호출 예시(`curl /api/sample/sample-user-info?id=user01`)를 보여준다.
- **진행 중 인시던트** — 평소 초록 "정상", 5xx가 임계치(최근 창에서 3건 이상)를 넘으면 빨강 "LIVE" 와 모니터링 이동 버튼이 나타난다.

### 3) API 목록 두 가지

- **최근 등록 API** — 최근 5건. 이름·경로(메서드 배지)·상태와 **수정** 버튼.
- **가장 많이 호출한 API** — 호출 수 상위 5건. 오류 건수가 있으면 빨갛게 표시된다.

### 4) 데이터소스 풀 사용률 · 할 일

- **데이터소스 풀 사용률** — 각 DB 연결의 사용 중 커넥션 비율을 막대로. 80% 미만 파랑, 80~95% 주황, 95%+ 빨강.
- **할 일** — 처리 대기 항목을 모아 보여주고, 누르면 해당 화면으로 이동한다.

| 할 일 항목 | 의미 | 이동 |
|---|---|---|
| API 사용 신청 대기 | 외부 시스템의 매핑 요청 | [승인 관리](07_승인관리.md) |
| 회원가입 승인 대기 | PENDING 사용자 | [승인 관리](07_승인관리.md) |
| 인증키 만료 임박 | 30일 이내 이용기간 종료 | [연계시스템](06_연계시스템.md) |
| DRAFT 상태 API | 등록 후 아직 활성화 안 한 API | [API 관리](04_API관리.md) |

## 자주 묻는 점

- **차트가 비어 있어요.** 아직 게이트웨이 호출 이력이 없어서다. 외부 호출이 한 번이라도 발생하면 자동으로 채워진다([11. 외부 API 호출 가이드](11_외부_API호출_가이드.md)).
- **숫자가 안 바뀌어요.** 5초 폴링이므로 잠시 기다리면 갱신된다.
