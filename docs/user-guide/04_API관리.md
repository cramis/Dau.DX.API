## 이 화면은 무엇

등록된 API를 보고 검색·관리하며, **새 API를 등록**하는 화면이다(`/api-list`). 이 플랫폼의 핵심 — 코딩 없이 SQL과 명세만 입력해 표준 REST API를 만든다.

## API 목록 화면

### 화면 구성

- 상단 지표 — **전체 API**, **운영 중**(ACTIVE), 셀프서비스 등록 비율, 평균 발급 소요.
- **신규 등록** 버튼(우상단) — 등록 마법사로 이동.
- 검색창 — 번호·이름·경로·그룹으로 검색.
- 상태 필터 — 전체 / 운영(ACTIVE) / 검토(DRAFT) / 비활성(INACTIVE).

### 표 컬럼

| 컬럼 | 설명 |
|---|---|
| API 번호 | 자동 채번된 식별자(정렬 가능) |
| API명 / 경로 | 이름과 호출 경로 |
| 그룹 | 분류(USER, GRADE 등) |
| 메서드 | GET / POST / PUT / DELETE |
| 데이터소스 | 연결된 DB |
| 상태 | 운영(초록) · 검토(주황) · 비활성(회색) |
| 인증 | 인증키 필요 / 공개 |

머리글을 누르면 정렬되고, 아래쪽에서 페이지를 넘긴다(`1 / N 페이지 · 총 N건`).

## 신규 API 등록 (5단계 마법사)

**신규 등록** 버튼을 누르면 마법사가 열린다(`/api-list/new`). 상단에 단계가 번호로 표시된다.

> 진행 순서. 기본정보 → SQL 작성 → 파라미터/응답 → 테스트 실행 → 발급.

### 1단계 — 기본정보

| 항목 | 설명 | 비고 |
|---|---|---|
| API 이름 | 표시 이름 | 필수 |
| 그룹 | 분류명 | 필수 |
| HTTP 메서드 | GET/POST/PUT/DELETE | 기본 GET |
| 경로(path) | 호출 경로(예 `sample-user-info`) | 필수. **중복확인** 버튼으로 사용 가능 여부 확인 |
| 상태 | DRAFT/ACTIVE/INACTIVE | 기본 DRAFT |
| 데이터소스 | SQL을 실행할 DB | 필수 |
| 인증 필수 | 체크 시 호출에 인증키 필요 | 기본 체크 |
| API 문서 노출 | 체크 시 공개 `/docs` 에 표시 | 기본 체크 |
| 설명 | 부가 설명 | 선택 |

경로를 입력한 뒤 **중복확인**을 눌러야 한다. 사용 가능하면 "사용 가능한 경로입니다.", 이미 있으면 "이미 사용 중인 경로입니다." 가 뜬다.

### 2단계 — SQL 작성

데이터를 꺼낼 SQL을 편집기에 작성한다.

- 입력 파라미터는 **`#{이름}`** 형식으로 바인딩한다(예 `SELECT ... WHERE user_id = #{id}`). 이 이름이 3단계의 파라미터 이름과 일치해야 한다.
- **SQL 검증** 버튼을 누르면 형식·실행 계획을 점검한다. 성공하면 "SQL 형식이 유효합니다." 와 실행 계획이, 실패하면 오류 메시지가 표시된다.

> 안전장치. 위험한 SQL(DELETE·DDL·다중문 등)은 정책상 거부된다. 조회 중심으로 작성한다.

### 3단계 — 파라미터 / 응답

두 표를 채운다.

**입력 파라미터** — SQL의 `#{...}` 변수와 1:1로 맞춘다.

| 열 | 값 |
|---|---|
| 이름 | `#{이름}` 과 동일 |
| 타입 | string / number / date / boolean |
| 필수 | 체크 시 호출에 반드시 필요 |
| 기본값 | 미입력 시 사용할 값(선택) |
| 설명 | 선택 |
| 마스킹 | 호출 이력에 남길 때 가릴 규칙 |

**응답 컬럼** — 응답으로 내보낼 컬럼(최소 1개 필요).

| 열 | 값 |
|---|---|
| 컬럼 | DB 컬럼명 |
| 타입 | VARCHAR, NUMBER 등 |
| 표시명 | 사용자용 이름(선택) |
| 마스킹 | 응답에서 가릴 규칙 |

마스킹 규칙은 7종이다 — `none`(없음)·`name`(이름)·`phone`(전화)·`email`(이메일)·`rrn`(주민번호)·`card`(카드)·`addr`(주소). 개인정보(PII) 컬럼에 지정하면 응답과 호출 이력에서 자동으로 가려진다.

### 4단계 — 테스트 실행

작성한 SQL과 파라미터로 **실제 DB 에 실행해** 결과를 확인하는 단계다. **저장 전에도** 동작한다(현재 폼 내용 그대로 실행).

- 파라미터 표에 값을 채우고(기본값은 미리 채워짐) **실행** 버튼을 누른다.
- 결과에 행 수·소요시간과 함께 **마스킹이 적용된 실제 응답**(운영과 동일한 모습)이 JSON 으로 표시된다.
- 조회(SELECT)는 기본 100행까지 표시되고, 더 많으면 **행 제한** 배지가 붙는다.
- **쓰기 SQL(INSERT/UPDATE/MERGE)은 실행 후 자동 롤백**된다 — 영향 행수만 확인하고 DB 는 원상복구(**롤백됨** 배지). 단, 시퀀스 번호 소모 등 일부 부수효과는 롤백되지 않는다. CALL(프로시저)은 테스트 실행이 차단된다.
- 테스트 실행은 호출 이력(모니터링)에 적재되지 않는다.

> 승인 전 검토에 활용 — DRAFT 상태(AI 초안 포함)도 실행되므로, **실행해 보고 결과를 확인한 뒤 승인**하는 흐름을 권장한다.

### 5단계 — 발급(등록)

하단 **등록** 버튼을 누른다.

- 등록 모드에서는 경로 **중복확인**을 먼저 해야 한다(안 했으면 "경로 중복확인을 먼저 해주세요.").
- 성공하면 "등록되었습니다." 후 목록으로 돌아간다.
- 발급 완료 화면에서 엔드포인트 주소·상태·인증 방식과 자동 생성된 문서, curl 예시를 확인할 수 있다.

> 등록 직후 상태가 **DRAFT(검토)** 면 외부 호출이 차단된다. 호출되게 하려면 상태를 **ACTIVE(운영)** 로 바꾼다.

## API 수정 · 삭제

목록에서 항목을 열면 등록과 같은 화면이 편집 모드로 열린다(`/api-list/[id]`).

- **수정 저장** — 변경 내용 저장.
- **삭제** — "정말 삭제하시겠습니까?" 확인 후 삭제.

## 상태 배지 의미

| 상태 | 배지 | 뜻 |
|---|---|---|
| ACTIVE | 운영(초록) | 외부 호출 가능 |
| DRAFT | 검토(주황) | 등록됨, 아직 호출 불가 |
| INACTIVE | 비활성(회색) | 사용 중지 |

상태 배지 옆에 보라색 **AI** 배지가 붙어 있으면 AI 서비스계정이 등록한 초안이다(아래 참고).

## AI 가 등록한 초안 — 승인 전 검토 체크리스트

AI(MCP 도구)는 API 를 **검토(DRAFT) 상태로만** 등록할 수 있고, 운영(ACTIVE) 전환은 관리자만 가능하다. 목록에서 보라색 **AI** 배지가 붙은 초안을 승인(ACTIVE 전환)하기 전에 반드시 아래를 검토한다.

> ⚠️ AI 초안은 사람과 동일하게 **쓰기 SQL(INSERT/UPDATE/MERGE)도 만들 수 있다**. 승인 = 외부에 실제로 열리는 순간이므로, 검토 없이 승인하지 말 것.

### 승인 전 체크리스트

- [ ] **SQL 내용** — 의도한 테이블·컬럼만 접근하는가. 특히 **非GET(쓰기) SQL 이면 어떤 데이터를 변경하는지** 한 줄씩 확인 (DELETE·DDL 은 시스템이 차단하지만 INSERT/UPDATE/MERGE 는 통과한다).
- [ ] **개인정보 마스킹** — 응답 컬럼 중 이름·전화·이메일·주민번호·카드·주소가 있으면 마스킹 규칙이 지정돼 있는가.
- [ ] **파라미터** — SQL 의 `#{...}` 와 파라미터 정의가 1:1 인가. 필수/기본값이 합리적인가.
- [ ] **경로·그룹** — 명명 규칙에 맞는가. 기존 API 와 역할이 겹치지 않는가.
- [ ] **인증·문서 노출** — 인증 필수 여부와 공개 문서(`/docs`) 노출 여부가 데이터 민감도에 맞는가.
- [ ] **데이터소스** — 올바른 DB 를 가리키는가 (운영/개발 혼동 주의).

문제가 있으면 ACTIVE 로 바꾸지 말고 편집 화면에서 수정하거나, 부적합하면 삭제한다. 승인(상태 전환) 기록은 수정자·수정일시로 감사 추적된다.

### AI 계정 관리

- AI 가 과도하게 초안을 만들면 [사용자 관리]에서 AI 계정(`ai-mcp01`)을 **비활성(INACTIVE)** 으로 바꾸면 즉시 차단된다.
- AI 의 생성은 분당 한도·미처리 초안 상한으로 제한돼 있다.
