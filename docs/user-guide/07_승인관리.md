# 07. 승인 관리

[← 목차로](README.md)

---

## 이 화면은 무엇

두 종류의 신청을 관리자가 처리하는 화면이다.

- **API 사용 신청 승인**(`/approvals/api`) — 외부(연계) 시스템이 특정 API를 쓰겠다고 올린 신청. 승인하면 해당 API가 그 시스템에 **매핑**된다.
- **사용자 가입 승인**(`/approvals/user`) — 신규 회원가입 신청. 승인하면 사용자가 **ACTIVE** 가 되어 로그인할 수 있다.

좌측 메뉴 **승인 관리**로 들어가며, 두 화면 모두 같은 방식으로 동작한다.

## 화면 구성

- 상단 지표 — 대기 / 승인 / 반려 건수, 평균 처리 시간(또는 활성 사용자 수).
- 탭 — **대기**, **승인**, **반려**. 기본은 대기 목록이다.

### 표 컬럼

**API 사용 신청** — 신청 시스템 / 대상 API / 사유 / 신청일 / 상태 / 처리.

**사용자 가입 신청** — 아이디 / 이름 / 기관·부서 / 이메일 / 사유 / 신청일 / 상태 / 처리.

## 승인 · 반려하기

**대기** 탭의 각 행에서 처리한다.

1. **승인** 버튼 — "이 신청을 승인하시겠습니까?" 확인 후 승인.
   - API 신청 승인 → 대상 API가 신청 시스템에 매핑된다.
   - 가입 신청 승인 → 사용자가 ACTIVE 로 전환된다.
2. **반려** 버튼 — 확인 후 **반려 사유**를 입력하면 반려 처리된다.

이미 처리된 신청은 승인/반려 버튼 대신 처리 시각이 표시된다.

## 상태 배지 의미

| 상태 | 배지 | 뜻 |
|---|---|---|
| PENDING | 대기(주황) | 처리 전 |
| APPROVED | 승인(초록) | 승인 완료 |
| REJECTED | 반려(빨강) | 반려됨 |

> 가드. 이미 처리된 신청을 다시 처리하려 하면 거부된다(중복 처리 방지).
