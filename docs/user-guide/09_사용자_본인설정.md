## 사용자 관리 (관리자)

전체 사용자를 보고 상태·권한을 관리하는 화면이다(`/users`).

### 화면 구성

- 상단 지표 — 전체 / 활성 / 대기 / 관리자 수.
- 상태 필터(전체·활성·대기·비활성·반려)와 검색(아이디·이름·부서).

### 표 컬럼

| 컬럼 | 설명 |
|---|---|
| 아이디 | 로그인 아이디 |
| 이름 | 사용자 이름 |
| 역할 | ADMIN(파랑) / USER(회색) |
| 기관 / 부서 | 소속 |
| 이메일 | 이메일 |
| 상태 | 활성(초록)·대기(주황)·반려(빨강)·비활성(회색) |

### 상태 바꾸기

각 행의 버튼으로 처리한다.

- **활성화** — 대기/비활성 사용자를 ACTIVE 로(로그인 가능). 확인창이 뜬다.
- **비활성화** — 활성 사용자를 INACTIVE 로(로그인 차단).
- **반려** — 대기(PENDING) 사용자를 REJECTED 로.

> 본인 계정은 직접 바꿀 수 없다. 본인 행에는 "본인 계정" 으로 표시되며, 시도하면 "본인 계정은 직접 변경할 수 없습니다." 가 뜬다.

활성화/비활성화는 [01. 시작하기](01_시작하기.md)의 로그인 잠금(5회 실패)·가입 승인과 연결된다.

## 본인 설정 (`/me`)

좌측 메뉴 맨 아래 **설정**에서 본인 정보를 관리한다. 세 탭으로 나뉜다.

### 기본 정보 🚧

> 🚧 **준비 중(mockup)** — 화면에서 수정·저장은 되지만 실제 DB에는 반영되지 않는다(본인정보 조회 자체는 실동작).

이름·휴대폰번호·이메일·기관명·부서명·전화번호를 수정하고 **저장**한다.

### 비밀번호 변경 🚧

> 🚧 **준비 중(mockup)** — 변경 동작이 아직 실제 반영되지 않는다.

현재 비밀번호·신규 비밀번호·신규 비밀번호 확인을 입력하고 **비밀번호 변경**을 누른다.

### 세션

로그아웃을 할 수 있다. 현재는 단일 세션만 지원하며, 다중 기기 로그아웃은 후속 단계다.
