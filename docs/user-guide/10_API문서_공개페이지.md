> 비로그인으로 열 수 있는 공개 API 문서 페이지(/docs) 사용법. 외부 개발자가 호출 가능한 API와 파라미터·응답을 찾고, OpenAPI 명세를 내려받는 법을 안내한다.

# 10. API 문서 공개 페이지

[← 목차로](README.md) · 대상: 외부 연계 개발자

---

## 이 화면은 무엇

로그인 없이 열 수 있는 **공개 API 문서**다(`/docs`). 관리자가 "API 문서 노출" 로 등록한 API들의 경로·입력 파라미터·응답 형식을 보여준다. 외부 개발자는 여기서 **무엇을 호출할 수 있는지** 확인한 뒤 실제 호출로 넘어간다.

> 보안. 문서에는 호출에 필요한 정보만 노출된다. 내부 SQL과 인증키 평문은 표시되지 않는다.

## 화면에서 할 수 있는 일

- 공개된 API 목록을 그룹별로 살펴본다(**운영(ACTIVE) 상태인 API 만** 노출된다).
- 각 API의 경로(`/api/sample/{경로}`), 메서드, 입력 파라미터(이름·타입·필수), 응답 컬럼을 확인한다.
- 인증 방식이 **X-Cert-Key**(헤더) 임을 확인한다.
- **직접 실행(Try it)** 으로 브라우저에서 바로 호출해 본다(아래).
- 문서를 파일로 내려받는다.

## 직접 실행 (Try it)

각 API 상세의 **직접 실행** 카드에서 발급받은 인증키와 파라미터를 입력하고 [실행] 을 누르면 **실제 게이트웨이를 호출**해 결과를 바로 확인할 수 있다.

- 인증키는 **저장되지 않는다** — 입력한 화면에서만 사용되고, 새로고침하면 사라진다.
- 호출은 실제와 완전히 동일하다 — 인증키·IP·기간·매핑 검증을 모두 통과해야 하고, 호출 이력에도 적재된다. 검증에 걸리면 같은 에러(`INVALID_CERT_KEY` 등)를 그대로 보여준다.
- ⚠️ **쓰기 API(POST 등)는 실제 데이터가 변경된다**(롤백 없음). 실행 전 확인창이 뜬다.
- 응답에는 마스킹 규칙이 적용된 실제 모습이 표시된다.

## OpenAPI 명세 내려받기

표준 OpenAPI 3.0.3 형식으로 제공되어, Swagger UI·Postman 등으로 바로 불러올 수 있다.

| 주소 | 내용 |
|---|---|
| `/openapi.json` | 공개 API 전체 명세 |
| `/openapi/{그룹}.json` | 특정 그룹만 |
| `/api/docs/apis` | 공개 API 목록(JSON) |

명세의 보안 스킴은 `apiKey` 방식이며, 헤더 이름은 **`X-Cert-Key`** 다. 인증키 평문은 명세에 들어 있지 않으므로, 발급받은 키를 직접 헤더에 넣어 호출한다.

## 다음 단계

문서에서 부를 API를 정했다면, 발급받은 인증키로 실제 호출한다. 호출 규칙·응답 형식·에러코드는 [11. 외부 API 호출 가이드](11_외부_API호출_가이드.md)를 본다.

호출하려면 먼저 관리자에게 다음이 준비돼 있어야 한다.

- 우리 시스템이 **연계시스템으로 등록**되고 **인증키**를 받았다.
- 부를 API가 우리 시스템에 **매핑**됐고, API 상태가 **ACTIVE** 다.
- 우리 출발지 **IP가 허용 목록**에 있고, **이용 기간** 안이다.
