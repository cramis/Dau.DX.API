이 문서 묶음은 **실제 사용자**를 위한 사용 설명서다. 두 독자를 함께 다룬다.

- **외부 연계 개발자** — 발급받은 인증키로 게이트웨이 API(`/api/sample/{경로}`)를 호출하는 사람.

## 상태 배지 범례

가이드 곳곳에 기능의 현재 상태를 표시한다.

- ✅ **실동작** — 실제 DB(dev Oracle)에 연결되어 동작하는 기능.
- 🚧 **준비 중(mockup)** — 화면은 있으나 저장·발송 등 실제 동작은 후속 단계. 지금은 데모용 가짜 응답이다.

현재 🚧 준비 중인 기능은 회원가입, 비밀번호 찾기, 본인정보 수정·비밀번호 변경, 인시던트 자동 감지, 알림 규칙이다. 나머지(로그인·API 관리·데이터소스·연계시스템·승인·모니터링 조회·게이트웨이 호출·사용자 관리)는 실동작한다.

## 데모(체험) 계정

체험용 시드 계정이다. 실제 운영 계정이 아니며, 백엔드를 `DXAPI_SEED_ENABLED=true` 로 띄워 시드했을 때만 존재한다.

| 아이디 | 비밀번호 | 권한 | 용도 |
|---|---|---|---|
| `admin01` | `admin01!` | ADMIN | 전체 관리(등록·승인·사용자) |
| `user01` | `user01!` | USER | 일반 사용자 흐름 |
| `user02` | `user02!` | USER(PENDING) | 승인 전 로그인 차단 확인용 |

로그인 화면 하단의 데모 계정 카드를 클릭하면 아이디·비밀번호가 자동 입력된다.
